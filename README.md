# Motion-Triggered Security Application
 
A classical computer vision project using Python and OpenCV. It watches a webcam
or a video file, detects and tracks moving objects, raises an alert when motion
persists, and saves a snapshot plus a CSV log entry as evidence.

## Techniques used
- Image Operations: resize, grayscale, Gaussian blur, drawing overlays
- Image Segmentation: MOG2 background subtraction, threshold, morphology
- Motion and Object Tracking: contours, bounding boxes, centroid trail
- Haar Cascade Classifier: face detection inside moving regions
 
## Requirements
- Python 3.9 or later (tested with Python 3.14.7)
- opencv-python, numpy (see requirements.txt)
 
## Setup
    git clone https://github.com/earljancoquilla/motion-security-cv.git
    cd motion-security-cv
    python -m venv venv
    .\venv\Scripts\Activate.ps1    # Windows PowerShell
    # Windows Command Prompt: venv\Scripts\activate.bat
    # macOS/Linux: source venv/bin/activate
    pip install -r requirements.txt
 
## How to run
    python make_sample_video.py                             # creates samples/intruder.mp4
    python motion_security.py --source samples/intruder.mp4 # recorded video
    python motion_security.py --source 0                    # live webcam
    python motion_security.py --source samples/intruder.mp4 --headless --output alerts/demo_output.mp4
 
Keys: q = quit, s = save screenshot, SPACE = pause.
Options: --no-faces disables Haar face detection, --headless runs without a window.
 
## Output
- alerts/alert_*.jpg  snapshots saved when an alert triggers
- alerts/alert_log.csv  timestamp, frame, objects, faces, snapshot path
- alerts/screenshot_*.jpg  screenshots saved with the s key
 
## Sample input
samples/intruder.mp4 (generated by make_sample_video.py)
 
## Configuration
Edit the constants at the top of motion_security.py (MIN_CONTOUR_AREA,
ALERT_FRAMES, COOLDOWN_FRAMES) to tune sensitivity.
 
## Limitations
Sudden lighting changes, camera shake and slow movement can cause false or
missed detections. Haar face detection works best on frontal, well-lit faces.
